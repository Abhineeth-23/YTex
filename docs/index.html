1

Download & Unpack

Click the download button above to get yt-smart-chapterizer.zip. Right-click and extract the zip file to a folder on your computer.

2

Open Chrome Extensions

In Google Chrome or any Chromium browser (Brave, Edge), navigate to chrome://extensions and switch on Developer mode in the top right.

3

Load Unpacked

Click the Load unpacked button and select the extracted folder. Pin the extension to your toolbar, open any YouTube video, and click the icon!

🔒

Zero-Leak Server Architecture

You don't need to create an account or provide an API key. All AI operations are proxied through a hardened server where API credentials remain locked in secure cloud memory and are never exposed to clients or the web.

🛡️

Strict User Privacy

The extension only activates on YouTube watch pages. It does not track your browsing activity, store personal information, or collect cookies or passwords.
